# SOS
Sécurité des systèmes d'exploitation 2025-2026
## Objectifs 
- décrire les composants architecturaux des systèmes d'exploitation Linux et Windows
- expliquer la stratégie choisie par chacun des systèmes Linux et Windows pour répondre aux nouvelles menaces
- expliquer et configurer le modèle d'autorisation des systèmes d'exploitation Linux et Windows
- expliquer et configurer les modules d'authentification basiques des systèmes d'exploitation Linux et Windows
- créer et configurer un domaine Windows simple, géré avec des politiques de groupe
- expliquer le fonctionnement et les limites des mécanismes de cloisonnement entre l'espace utilisateur et l'espace noyau
- lister, décrire et mettre en oeuvre les primitives de durcissement permettant de restreindre les ressources accessibles à un processus
- lister, décrire et mettre en oeuvre les primitives de confinement permettant d'enfermer un processus dans un bac à sable séparé des ressources de l'OS hôte
- construire un container sécurisé pour y confiner une application ou un outil sous Linux
- mettre en oeuvre les mécanismes de chiffrement pour protéger le contenu en cas de vol d'un container, d'une VM ou d'un laptop
- vérifier et éprouver la sécurité des mécanismes de sécurité présentés et en particulier de l'authentification Windows
- discuter l'application de concepts équivalents dans un OS représentant une évolution de l'OS Windows ou Linux
